# Dutch-arbitrage Docker path: retired

This was an experimental dry-run/live-arbitrage container design. It is not a
supported deployment or operating path. Its activation commands, credential
instructions and runnable examples have been removed to prevent the historical
document from being mistaken for current authority.

The underlying diagnostics may remain useful for research, but their evidence
class cannot be promoted to executable or live evidence. There is no approved
autonomous live-order path; funding is CLOSED and WO-67 is BLOCKED.

Use only the canonical VPS controls in `AGENTS.md`, `docs/OPERATING_STATE.md`
and `docs/POLYMARKET_VPS_DOCKER_RUNBOOK.md`. See the dated repository audit for
remaining code and deployment gaps.
