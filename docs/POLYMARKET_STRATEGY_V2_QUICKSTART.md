# Strategy V2 quickstart: retired

The local Strategy V2 launcher is retired. Anchored-edge code remains
diagnostic/historical and may be exercised only through a scoped work order in
an isolated VPS environment. It does not generate build authority, a promotion
decision or permission to trade.

Current research is frozen to `docs/EXPERIMENT_REGISTRY.md`; current runtime
state comes from the generated operating state. See `AGENTS.md` and the dated
repository line audit before planning any rerun.
